# Fortune Finds

Public website: https://michelleproject.github.io/fortune-finds/

This repository contains the public website export. GitHub Actions publishes the site folder to GitHub Pages on every push to main.

The homepage, beginner guide, planned pricing, about, and privacy pages are available. Online workspace access and recommendations are coming later. GitHub Pages does not run the application's database, authentication, or automation backend.

The application source is maintained separately. Regenerate this export in the application workspace with npm run build:pages, then commit and push the updated export. No credentials, private records, or application database are included.
